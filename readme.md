## ☕ Overview

**Lia’s Coffee** is a simple yet elegant website designed for a fictional local coffee shop.  
It focuses on **clean design**, **smooth navigation**, and **ease of use** — allowing customers to explore the menu, learn about the shop, and create accounts through login/signup features.

This project was developed using **CodeIgniter 4** for backend logic and **HTML/CSS** for frontend design, ensuring scalability and maintainability.

---

## 🌟 Features

| Section | Description |
|----------|-------------|
| **Home Page** | Showcases the brand name and welcoming hero banner. |
| **Menu Page** | Displays featured coffee drinks and snacks with images and prices. |
| **About Us** | Describes the coffee shop’s story, mission, and cozy atmosphere. |
| **Login & Signup** | Simple authentication system for users to register and log in. |
| **Responsive Design** | Works seamlessly on desktops, tablets, and mobile phones. |
| **Sticky Navbar with Fade Effect** | Smooth navigation bar that stays visible as users scroll. |

## 🧩 Technologies Used

#### 🖥️ Frontend
- HTML5  
- CSS3 (Custom + Inline Styles)
- Tailwind-like responsive layout principles

#### ⚙️ Backend
- PHP 8+
- CodeIgniter 4 Framework

#### 🗄️ Database
- MySQL (for user authentication and menu data)

#### 🧱 Tools
- Visual Studio Code  
- Docker (for local development environment)  
- phpMyAdmin (for DB management)
